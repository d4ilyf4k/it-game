# Центр Инвест Банк / IT LAB

Локальная браузерная игра о трёх IT-профессиях: разработчик, белый хакер и сисадмин.

## Запуск

```sh
python3 -m http.server 8785 --bind 127.0.0.1 --directory dist
```

Открыть http://localhost:8785/ . Установка зависимостей не требуется.

## Проверка

При установленном Node.js:

```sh
npm test
```

## Возможности

- Сюжет, 3D-серверная, защита сети, интерактивный выпуск патча.
- Тайкон с бонусами профессий, 30 CPU и 30 GPU, расчётом узкого места.
- Клановые войны, 10 предметов-усилений, рынок, фьючерсы, аукционы.
- 8 тем базы и 3D-офис.
- Админка для показа: F2; переходы к подготовленным этапам игры.

WASD — движение, E — взаимодействие, Shift — бег. Музыка отключается в настройках.
Сохранения хранятся в браузере. Демонстрация использует отдельное сохранение.
Торговля и кланы — локальная симуляция с NPC. Реальных банковских операций нет.

## Структура

`dist/` — приложение и ресурсы; `tests/` — автоматические проверки. Three.js включён локально, лицензия находится в `dist/vendor/THREE-LICENSE.txt`.
